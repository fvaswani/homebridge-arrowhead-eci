# Arrowhead EC-i implementation plan

Goal: publish an experimental open-source HOOBS/Homebridge plugin with honest compatibility claims.
Architecture: independent TCP client, validated Homebridge platform, local simulator tests.
Tech stack: Node >=20, CommonJS, node:test, Homebridge HAP.
Spec: ../specs/2026-09-16-plugin-design.md

1. Client and protocol tests: create src/client.js and test/client.test.js. Implement the spec's ArrowheadClient API. Use a local TCP server, verify fragmented STATUS events, event/response separation, disconnected state, rejected/timeout commands, reconnect and no replay. Run node --test test/client.test.js.
2. Homebridge adapter and tests: create index.js, src/platform.js, src/config.js, config.schema.json, test/platform.test.js and package.json. Validate host, port, area, zone numbers, duplicate zone IDs, booleans and PIN input. Only enable controls when explicitly configured and credentials are valid. Use stable UUIDs, accessory reconciliation, actual HAP services and communication errors. Run npm test.
3. Distribution: README, MIT LICENSE, upstream notice, security/contribution guidance, example config, CI matrix and npm pack. Run tests on Node 20/22/24; inspect package contents and secret scan. Verify real Homebridge loading in isolated temporary configuration with no panel connection. Publish GitHub repository and experimental prerelease tarball after review. Do not connect to the real alarm. npm registry publishing remains dependent on account authentication.
