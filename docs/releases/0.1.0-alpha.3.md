This experimental release fixes queued alarm commands that could otherwise
outlive their HomeKit request, masks the PIN in the HOOBS visual editor, and
adds plug-in artwork. It is intended for single-area EC-i installations using
local Serial over IP with MODE 4. Controls remain disabled by default.

## Changes since alpha.2

- Start the five-second control deadline when a request enters the queue.
  Expired requests reset the connection and discard queued commands; commands
  are never replayed after reconnect. A command already transmitted may still
  have taken effect, so check the keypad before retrying.
- Set HOOBS's explicit password widget for the PIN field. This masks the field
  on screen without changing storage or transport security.
- Include the shield-and-arrowhead SVG and PNG, README branding, and the
  Homebridge settings-header image.
- Package hardware-validation, HOOBS configuration, and contribution documents.
  README documentation links use full repository URLs so they work on npm.
- Correct the settings notice to reflect the documented pilot's Away/Off
  controls and Home/Stay arming, while retaining the outstanding validation limits.

## Compatibility and validation limits

Node.js 20 or later and Homebridge 1.8.4 or later, below version 3, are required.
The existing pilot uses HOOBS 5.1.8, Homebridge 1.8.4, Node 20.19.1, and EC-i
firmware 10.3.61 with an EC-IoT module. Its hardware results predate this release;
alpha.3 has not undergone a new hardware acceptance cycle.

Real alarm-trigger, tamper, battery, and EliteCloud coexistence behavior remain
unvalidated. Sparse startup status inference is experimental and opt-in.
Serial over IP is unencrypted and unauthenticated; use a trusted local network.
Controls affect the whole panel, so multi-area installations are unsupported.

HOOBS catalogue listing and certification are not claimed. The pilot's local
configuration-page and icon workarounds are not installed by this package.

## Installation

Install the prepared tarball into the intended Homebridge environment:

```sh
npm install -g /absolute/path/to/homebridge-arrowhead-eci-0.1.0-alpha.3.tgz
```

The published version can also be installed with:

```sh
npm install -g homebridge-arrowhead-eci@0.1.0-alpha.3
```

HOOBS users must target their intended bridge using its supported installation
process; a global npm install does not necessarily target a HOOBS bridge.
See the [README](../../README.md), [hardware report](../hardware-validation.md),
and [HOOBS configuration notes](../hoobs-configuration.md).

## HOOBS discussion

The [September 2021 Reddit discussion](https://www.reddit.com/r/HOOBS/comments/pp1ges/how_to_make_plugin_appear_in_hoobs/)
directs community developers to contact the HOOBS team through a GitHub issue.
In the [linked HOOBS issue](https://github.com/hoobs-org/HOOBS/issues/1523), a
maintainer explains that an unpublished development plug-in will not appear in
the plug-in section. This is historical guidance, not confirmation of current
alpha-tag indexing or certification requirements. No submission has been made.
